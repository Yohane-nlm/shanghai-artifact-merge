# 素材、创作与许可

## 项目创作

项目受同类碰撞合成玩法启发，采用独立的程序实现、界面设计和文物图像。

这是独立文博学习作品，非上海博物馆官方项目。馆名用于说明文物的收藏来源。

## 文物图标

`assets/` 中的九幅 PNG 由文字描述生成，为原创艺术化示意。图像服务于游戏识别，文物的具体形制、年代和学术信息以[馆方资料](sources.md)为准。合成顺序和图标尺寸按玩法设计。
