# 合成上博 · 镇馆之宝

一款以上海博物馆藏品为主题的浏览器合成小游戏。投放文物、触发连合，逐步点亮九件珍藏的知识图鉴。

## 本地运行

直接打开 `index.html` 即可试玩。开发时也可以启动静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。项目的脚本和图像均随源码提供。

## 操作

- 鼠标：移动瞄准，按下投放
- 触屏：拖动瞄准，松手投放
- 键盘：方向键瞄准，空格投放，P 暂停，R 重开
- 图鉴：点击已解锁的文物，查看知识卡和馆方资料
- 音效：点击音符按钮切换；支持的设备同时提供轻触反馈

最高分与图鉴保存在当前浏览器。系统的“减少动态效果”设置会简化画面反馈。

## 主要功能

- 相同文物碰撞合成，支持连续合成
- 弹性碰撞、接触动量传递与合成反馈
- 文物知识提示和可回看的珍藏图鉴
- 暂停、重开、最高分记录及键盘操作
- 可选 WebMCP 状态读取与投放接口

## 验证

需要 Node.js 18 或更新版本：

```bash
npm test
```

测试覆盖投放、合成、图鉴、暂停重开、满线、接触响应、边界和减少动态效果。测试在 Node.js 中运行游戏逻辑，浏览器画面、音频和触屏体验仍应在目标设备上检查。
